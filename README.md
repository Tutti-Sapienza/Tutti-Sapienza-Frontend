# Tutti Sapienza Frontend

Source-only checkpoint for the universal free-education and community-owned DAO website vision. Artist collections, school fees, reviewed AI lessons and child-owned evolving credentials are described as development plans. The Founders Collection sale stays disabled. Existing wallet handlers request accounts only; membership verification, signing and transactions are not implemented here.

This checkpoint omits private whitepaper review files, generated previews, reports, build output and caches. The page's /docs download links require separately approved publication assets; those assets are deliberately absent from this source checkpoint. Do not merge or deploy it automatically.

Run npm ci --ignore-scripts, npm test -- --watchAll=false --runInBand, and npm run build. Locked dependencies and contracts are unchanged. The source base is 6c511c89331fc3c8005af877832a7c2811e6ef28. Public hosting/domain and publication approval remain unresolved.
